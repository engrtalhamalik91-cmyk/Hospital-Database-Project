# 🏥 Automated Hospital Patient Analytics Pipeline (Python)

A production-ready data analytics pipeline engineered to automate patient check-ins, validate clinical biometric matrices, simulate real-time patient monitoring streams, and secure structural enterprise database logs.

## 🛠️ Technological Architecture
* **Core Runtime Engine:** Python 3.x
* **Core Manipulators:** Python Native `csv` engine (Bypassing heavy dependencies via custom loops)
* **Statistical Processing Extension:** Pandas Framework
* **Spreadsheet Styling Engine:** OpenPyXL Data Formatting Driver

## 📊 Analytical Guardrails & Principles Formulated

### 1. Advanced Structural String Cleaning
* Enforced **Defensive Text Normalization** pipelines using `.strip().lower()` to wipe out accidental user whitespaces and standardise alphanumeric mapping variations (e.g., catching `Karachi`, `karachi `, or `KARACHI`).
* Utilised internal **Substring Mining (`in` keyword checks)** to map nested medical parameters, enabling high-risk allergy traps to flag conditions seamlessly inside full medical history texts.

### 2. Physiological Outlier Controls
* Integrated strict **Domain Range Boundaries** (`90.0 <= temperature <= 110.0`) inside mathematical sum aggregation loops. 
* This prevents human typing traps (like entering a rushed literal `0.0`) from bypassing data type checks and distorting critical statistical mean outcomes.

### 3. Dual-Backup Memory Storage Matrix
* Built a synchronized parallel export compiler that updates both a plain-text database backup (`.csv`) and a corporate-ready executive sheet (`.xlsx`) simultaneously.
* Configured advanced worksheet parameters to enforce permanent **bold structural headers** and dynamically scale column widths to fit data length profiles automatically.
